# Forecasting results

This folder contains the main outputs generated by `scripts/forecasting/02_aoi_malaria_forecasting.R`.

## Files

### `m2_cross_validation.csv`

Performance of the final M2 model under five-fold year-grouped cross-validation.

The file also includes two reference benchmarks:

- spatial persistence
- AOI mean only

Performance metrics include RMSE, MAE, predictive R², correlation-based R² and bias.

### `m2_external_test.csv`

Pooled performance across the three independent external target years:

- 2009
- 2016
- 2024

Results are reported for:

- the spatial component
- reconstructed log-incidence
- reconstructed incidence

The file compares M2 with temporal and spatial persistence benchmarks.

### `m2_external_test_by_year.csv`

External-test performance of M2 reported separately for target years 2009, 2016 and 2024.

### `m2_best_tuning.csv`

Hyperparameter combination selected for the final Random Forest M2 model.

## Reproducibility

These outputs are generated directly from the prepared datasets distributed in `data/forecasting/` and reproduce the final M2 results reported in the CHANGE project analysis.
