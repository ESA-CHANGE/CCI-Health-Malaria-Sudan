# ESI results

This directory contains the outputs generated by the **Environmental Suitability Index (ESI)** analysis for the CHANGE UC5 Malaria case study.

## MAP–ESI annual comparison

The comparison figure should be stored in this directory, for example as:

```text
results/esi/map_esi_comparison_2000_2024.png
```

The figure compares annual MAP *Plasmodium falciparum* incidence and ESI for Sudan and South Sudan over the period 2000–2024.

### Figure caption

**Figure 4-44. Standardised annual MAP *P. falciparum* incidence and ESI in Sudan and South Sudan, 2000–2024.** Solid lines show annual spatial medians and shaded areas the Q05–Q95 spatial distributions. Dotted horizontal lines indicate the variable-specific minimum–maximum range of annual Q50 values observed during 2000–2008. From 2009 onward, points are green when the corresponding Q50 is within its own reference range and red when it is outside.

## Interpretation

The figure is intended to support visual comparison between malaria incidence and environmental suitability while preserving variable-specific reference ranges.

Standardisation is used only to place MAP incidence and ESI on a common graphical scale. The within-range / outside-range classification is based on the original Q50 values.

For each country and variable, the historical reference range is defined by the minimum and maximum annual Q50 values observed during 2000–2008.

Annual observations from 2009 onward are evaluated independently for MAP incidence and ESI against their corresponding historical reference ranges.
