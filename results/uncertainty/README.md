# MAP outcome uncertainty results

This folder contains the outputs generated by `scripts/uncertainty/03_map_outcome_uncertainty.R`.

## Files

### `map_uncertainty_summary.csv`

Summary of M2 performance under MAP incidence uncertainty for target years 2009, 2016 and 2024.

For each year, the file reports:

- performance against the MAP central estimate
- Monte Carlo median RMSE
- 2.5th and 97.5th percentiles of RMSE
- Monte Carlo median MAE
- 2.5th and 97.5th percentiles of MAE
- Monte Carlo median predictive R²
- 2.5th and 97.5th percentiles of predictive R²
- percentage of simulations with predictive R² below zero

### `map_uncertainty_simulations.csv`

Complete Monte Carlo results.

Each row represents one target year within one Monte Carlo simulation and includes:

- simulation identifier
- target year
- sampled quantile
- simulated spatial target standard deviation
- RMSE
- MAE
- predictive R²
- bias

With 10,000 simulations and three target years, the file contains 30,000 simulation-year results.

### `map_uncertainty_sensitivity.png`

Summary figure comparing performance against the MAP central estimate with the Monte Carlo median and 95% uncertainty interval for:

- RMSE
- MAE
- predictive R²

## Reproducibility

These outputs are generated directly from the prepared dataset distributed in `data/uncertainty/` and reproduce the final MAP outcome-uncertainty analysis used for the malaria case study.
