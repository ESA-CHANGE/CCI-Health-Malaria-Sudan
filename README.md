# Malaria in Sudan and South Sudan

Analysis of malaria dynamics and their relationship with environmental and Earth Observation-derived information for the CHANGE UC5 Malaria case study in Sudan and South Sudan.

## Description

This repository contains the analysis code developed for the **CHANGE UC5 Malaria** case study.

The use case investigates malaria dynamics in Sudan and South Sudan and explores how Earth Observation and environmental information can support the analysis of malaria incidence, environmental suitability, modelling, and associated uncertainty.

The analytical workflow is organised into three main components:

- **ESI** – analysis of the Environmental Suitability Index and its relationship with malaria incidence estimates;
- **Modelling** – development and evaluation of statistical or predictive models linking malaria-related outcomes with environmental and Earth Observation-derived variables;
- **Uncertainty** – assessment and communication of uncertainty associated with input data, derived indicators, model outputs, and comparisons.

These components are developed as separate but related analysis workflows within the repository.

## Getting Started

### Dependencies

The analyses are primarily implemented in **R**.

Dependencies may differ between the ESI, modelling, and uncertainty components. Requirements specific to each workflow are documented in the corresponding script directories.

Scripts are designed to use relative paths and should normally be executed from the root directory of the repository.

### Installing

Clone the repository:

```bash
git clone https://github.com/ESA-CHANGE/CCI-Health-Malaria-Sudan.git
```

Move to the repository directory:

```bash
cd CCI-Health-Malaria-Sudan
```

Install the R packages required by the analysis component that you intend to run.

Further information on component-specific dependencies and input data is provided in the corresponding directories.

A general repository structure is expected to follow:

```text
.
├── data/
├── scripts/
│   ├── esi/
│   ├── modelling/
│   └── uncertainty/
├── README.md
└── LICENSE
```

The structure may evolve as the UC5 analysis develops.

### Executing program

Individual analysis workflows are organised under the `scripts/` directory.

The main components are:

```text
scripts/esi/
scripts/modelling/
scripts/uncertainty/
```

Each component contains the scripts and documentation required for the corresponding analysis.

Where available, component-specific `README.md` files provide details on:

- required input data;
- software dependencies;
- analysis parameters;
- execution order;
- outputs generated by the workflow.

Analyses should generally be run from the repository root so that relative paths to data and outputs remain consistent.

## Help

Before running an analysis, check the corresponding component documentation under `scripts/`.

Common issues may include:

- missing input datasets;
- missing R packages;
- incorrect working directory;
- differences in local directory structure.

The repository root should normally be used as the working directory when executing analysis scripts.
